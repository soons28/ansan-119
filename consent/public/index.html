💡 소집동의서 작성기 사용 방법

임시총회 위임장(소집동의서)을 작성하고 출력하는 프로그램입니다.

📌 사용 순서
  1. 위임인 정보 입력: 성명, 생년월일(숫자 7자리, 예: 9501011), 주소, 소유 동호수, 연락처를 입력합니다.
  2. 실시간 미리보기: 우측 영역에서 글씨 인쇄 위치와 오탈자를 실시간 확인합니다.
  3. 인쇄 / 제출: 🖨️ 즉시 인쇄 버튼으로 출력하거나, 📁 제출하기 버튼을 눌러 구글 드라이브에 문서를 제출합니다.
  4. ⚠️ 주의사항: 제출하기 버튼을 누른 후, 화면에 '제출이 완료되었습니다.' 알림 팝업창이 나타나고 초록색 '업로드 성공!' 메시지가 뜨기 전까지는 절대 창을 닫지 마세요.
🔧 인쇄 위치 미세조정
프린터마다 인쇄 여백 오차가 있을 수 있으므로 하단 '출력 글자 위치 미세조정' 탭을 펼쳐 항목들의 X, Y 좌표를 1pt 단위로 직접 변경해 정렬할 수 있습니다.
💾 오프라인 단독 구동
빌드 스크립트 실행 후 완성되는 index.html 파일은 내부 자원이 전부 텍스트로 합쳐져 있어, 인터넷 연결 없이 브라우저 더블클릭만으로 실행 가능합니다.
